# WRQ
<img src="WRQ_top.png">

Wait state insertion module. For connection to the CPU_8080 processor board - https://github.com/R2AKT/CPU_8080.

Generation of a CPU module 'Wait' signal upon request from a slow device.

Status: Under testing.
